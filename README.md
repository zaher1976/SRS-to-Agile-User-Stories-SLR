# From Software Requirements Specifications to Agile User Stories Using Large Language Models

**A Structured Critical Review and Proposed Evaluation Framework**

Authors: **Zaher Fadhil Raham** and **Sura Salah**  
Working manuscript: [Structured Critical Review (Word)](manuscript/SRS_Structured_Critical_Review_Proposed_Evaluation_Framework_2026-11-03.docx)

## Review design

This is a **structured critical review** that purposively selects source-verifiable publications for task-aware comparison. Study selection and critical synthesis were performed **by a single reviewer**, not by independently adjudicated multiple reviewers. The review is not presented as a completed PRISMA systematic review or as exhaustive evidence identification.

Section **6** is the principal methodological contribution: a **proposed** source-grounded evaluation framework for SRS-to-Agile-user-story transformation. It specifies atomic obligation coverage, claim-source faithfulness, bidirectional traceability, story quality, acceptance-test readiness, robustness, and human revision effort. The protocol has **not** been empirically validated.

## Appendix A: scoping of the literature landscape

The bibliographic context includes 93 Scopus entries, 28 IEEE Xplore entries and 86 ScienceDirect citation-collection entries, totaling **207 imported entries**. DOI/title matching detected **26 duplicate entries**, leaving **181 distinct bibliographic candidates**. These counts describe a literature landscape, **not the number of included studies**. The ScienceDirect list is not represented as a fully audited native search execution.

The manuscript places this descriptive map and its Figure A1 in **Appendix A**, rather than treating it as a completed PRISMA inclusion flow.

### Evidence provenance

There are 26 original abstracts located in cross-source exports and 50 source-linked non-verbatim descriptions, plus nine publication containers and eight records lacking verified original abstracts. Source-linked descriptions are not represented as original publisher abstracts. The repository does not redistribute publisher full texts or private reviewer evaluations.
