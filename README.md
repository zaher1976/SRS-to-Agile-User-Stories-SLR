# From Software Requirements Specifications to Agile User Stories Using Large Language Models

**Reproducibility companion — author-review package v0.1.0 (2026-11-03)**

Authors: **Zaher Fadhil Raham** and **Sura Salah**.

This project accompanies a PRISMA-informed systematic evidence review of LLM-assisted requirements-to-user-story conversion, prompt engineering, user-story quality, acceptance criteria, and traceability. Bibliographic identification is audited; the **181 distinct bibliographic candidates are not 181 included studies**.

## Data and study status

The release package prepared for this repository includes:
- `data/bibliographic_candidates_181.csv`: bibliographic metadata only, not publisher abstracts.
- `data/identification_counts.csv`: imported and deduplicated counts.
- `data/scopus_abstract_provenance_93.csv`: source traceability.
- `data/source_linked_scopus_76.csv`: 26 original abstracts located in cross-source exports and 50 source-linked descriptions. **Descriptions are not substitutes for publisher abstracts.**
- `data/verified_source_tables.xlsx`: release-safe tables without individual reviewers' confidential decisions.
- `scripts/verify_package.py`: count and provenance checks.
- `manuscript/`: author-review Word/PDF, not an accepted or published article.

Eight records lack verified abstracts; nine identified records are proceedings/handbook containers, not individual empirical articles. All remain traceable in the private audit and should not be silently deleted from identification counts.

## Scientific safeguards

This repository must not be represented as a completed independently adjudicated PRISMA study-inclusion flow. Final study inclusion, full-text eligibility, and inter-rater agreement require independent documented decisions. We do not redistribute third-party copyrighted abstracts or publisher full texts.
