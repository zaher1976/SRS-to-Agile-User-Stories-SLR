# Publication workflow

1. Confirm public GitHub files, and add the prepared release archive contents (see the Google Drive ZIP).
2. Validate public metadata and tables against original records.
3. Enable the repository in the Zenodo GitHub integration, using **Sync now** if needed.
4. Create a versioned GitHub release only after the contents and Zenodo integration are confirmed.
5. Verify the resulting DOI and metadata before adding them to the manuscript.
6. Never represent this identification ledger as a completed study-inclusion flow, and never publish confidential reviewer decisions or third-party publisher full texts.
